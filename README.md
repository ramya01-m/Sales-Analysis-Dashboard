# Sales Analysis Dashboard

## 📌 Project Overview

The **Sales Analysis Dashboard** is a beginner-level data analytics project created to analyze sales performance and understand key business metrics.

The project uses **Excel and Power BI** to prepare, analyze, and visualize the data. **SQL Server and SSMS** were used to learn and execute SQL queries for data analysis.

The main focus of this project is to understand sales performance, customer satisfaction, discount patterns, and order processing time through interactive dashboards.

---

## 🎯 Project Objectives

* Analyze sales performance using a structured sales dataset.
* Understand customer satisfaction levels.
* Analyze discount patterns.
* Monitor order processing time.
* Create a dashboard using Excel.
* Create an interactive dashboard using Power BI.
* Learn and execute SQL queries using SQL Server and SSMS.
* Present important business metrics through visualizations.

---

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning, preparation, analysis, and dashboard creation
* **SQL Server** – Database storage and SQL analysis
* **SSMS** – Writing and executing SQL queries
* **Power BI** – Interactive dashboard and data visualization

The project uses a **Sales Performance Dataset** containing **1,000 records**.

## 📈 Power BI Dashboard

Power BI was used to create an interactive dashboard for analyzing sales performance.

The dashboard focuses on:

* Sales performance
* Customer satisfaction
* Discount analysis
* Order processing time
* Sales target monitoring

### Key KPIs

| KPI                           |     Value |
| ----------------------------- | --------: |
| Average Customer Satisfaction |  2.96 / 5 |
| Average Discount              |    14.99% |
| Average Order Processing Time | 4.96 days |

A **Sales Target Gauge** is also included to monitor sales performance against the target.
